One-Shot System Snapshot (sys_snapshot.py)
========================================
Coded by: Muse Spark (Meta AI assistant)

License: MIT (see LICENSE file)

WHAT IT DOES:
Prints/saves OS, CPU, RAM, disks, top-5 processes and boot time as text or JSON.

REQUIREMENTS:
Python 3.8+ only - works with stdlib; better with psutil: pip install psutil

HOW TO RUN:
python sys_snapshot.py --help
python sys_snapshot.py
python sys_snapshot.py --json --save snap.json

PLATFORM:
Windows + Linux + Mac: yes.
